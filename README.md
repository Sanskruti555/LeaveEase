# LeaveEase

LeaveEase is a Leave Management System built using Node.js, Express.js, and MySQL.

## Features

- Company Registration
- Email OTP Verification
- JWT Authentication
- Role-Based Access Control
- Leave Management
- Secure Password Hashing
- Repository-Service-Controller Architecture

## Tech Stack

- Node.js
- Express.js
- MySQL
- JWT
- Bcrypt
- Nodemailer
